# SAT Prep Pro Mastery question packs

This directory holds the skill-grouped SAT question-bank data for `src/components/MasteryQuestionBank.tsx`.

The original 4-unit starter roadmap remains visible until `index.json` is uploaded here.

To deploy the full library, unzip `sat-prep-mastery-bank-assets.zip` and upload `index.json` and all `uNN.json.gz` files into this same folder. Keep the filenames unchanged. Each compressed pack is loaded only when a student opens its skill unit.

The content was extracted from user-supplied PDFs. Confirm that you have permission to republish source questions before making the generated packs publicly available.
